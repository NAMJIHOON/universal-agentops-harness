# Task Types

Classify each request before execution so the right workflow and checks are used.

## Feature Development

Use for new behavior or enhancement requests.

Required outputs:

- Implementation plan
- Impact analysis
- Verification report
- PR summary or change report

## Bugfix

Use for broken or unexpected behavior.

Required outputs:

- Reproduction or location notes
- Root-cause summary
- Regression verification
- Risk and rollback notes

## Infrastructure Change

Use for deployment, environment, networking, CI/CD, cloud, containers, or operational changes.

Required outputs:

- Impact analysis
- Precheck results
- Runbook
- Rollback plan

## Incident Response

Use for active or recent service-impacting issues.

Required outputs:

- Symptoms
- Root-cause hypothesis
- Immediate action
- Verification
- Incident report

## Document Generation

Use for specs, runbooks, reports, summaries, and handoff docs.

Required outputs:

- Selected template
- Draft
- Review notes
- Final document

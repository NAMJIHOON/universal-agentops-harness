# Delivery Ready Gate

## When This Gate Is Used

Use before handing ProductOps outputs to Codex implementation.

## Required Artifacts

- PRD or product brief
- MVP scope
- Sprint plan
- Acceptance criteria
- Codex task backlog
- Domain map hints

## Required Checks

- Backlog quality rubric
- Codex task quality rubric
- MVP scope quality rubric

## Pass Criteria

- Backlog and Codex tasks score 4 or higher.
- Each task has goal, domain, likely files, acceptance criteria, and verification commands.
- Product questions are resolved or separated from implementation.
- Risks and rollback notes are included for sensitive work.

## Block Conditions

- Codex would need to guess the implementation goal.
- Stories are too large for focused execution.
- Acceptance criteria are missing.
- Domain, data, API, security, or rollback risk is hidden.

## Recommended Next Action

If passed, hand off to Hermes Codex Task Writer. If blocked, return to sprint planning or backlog translation.

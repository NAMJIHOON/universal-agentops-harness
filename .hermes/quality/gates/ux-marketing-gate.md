# UX Marketing Gate

## When This Gate Is Used

Use after UX and marketing sprint planning and before backlog translation.

## Required Artifacts

- UX flow brief
- Screen list
- User journey
- Marketing brief
- Landing page copy
- Experiment plan

## Required Checks

- UX quality rubric
- Marketing quality rubric
- Customer segment quality rubric

## Pass Criteria

- UX and marketing score 4 or higher.
- Primary flow and screen purposes are clear.
- Core message aligns with target segment and pain.
- Experiment hypothesis and metrics are defined.

## Block Conditions

- UX flow does not match the MVP goal.
- Screen list misses critical states or roles.
- Marketing copy is generic or unsupported.
- Claims are misleading or not testable.

## Recommended Next Action

If passed, create the sprint plan and Codex task backlog. If blocked, refine UX flow, screen list, positioning, or campaign hypothesis.

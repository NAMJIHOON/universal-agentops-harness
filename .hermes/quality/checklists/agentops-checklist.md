# AgentOps Checklist

Use this checklist to evaluate Hermes workflow and handoff quality.

## Hermes Workflow Quality

- Workflow type matches the task.
- Required agents are named.
- Inputs and outputs are explicit for each step.
- Handoff target is clear.
- Memory files used or updated are identified.
- Risk policy is applied when needed.
- Quality gate decision is recorded.
- Codex receives only implementation-ready tasks.
- Follow-up actions are assigned to the correct layer.

## Handoff Quality

- Context is sufficient.
- Scope is narrow.
- Constraints are explicit.
- Verification expectations are included.
- Rollback or release implications are named.

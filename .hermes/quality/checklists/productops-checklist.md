# ProductOps Checklist

Use this checklist before ProductOps outputs become implementation backlog.

## Idea To MVP Readiness

- Idea has a clear user, problem, and desired outcome.
- Pain points are tied to workflow steps and evidence.
- Target segment separates user, buyer, and approver when relevant.
- Competitors and substitutes are considered.
- Value proposition is specific and testable.
- PRD defines goals, non-goals, requirements, metrics, and risks.
- MVP scope separates must-have, should-have, could-have, and later.
- UX flow covers primary path, variants, empty states, errors, and permissions.
- Marketing brief defines segment, message, channels, and experiment hypothesis.
- Sprint plan slices work by user value.
- Product questions are separated from implementation tasks.

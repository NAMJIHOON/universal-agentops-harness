# Release Checklist

Use this checklist before merge, deployment, release, or stakeholder handoff.

## Release Readiness

- Final verification commands and results are recorded.
- Required tests, build, lint, type, syntax, and security checks passed or skips are explained.
- PR review findings are resolved or accepted.
- No unresolved P0 or P1 findings remain.
- Rollout plan is documented.
- Rollback plan is documented.
- Data, API, security, configuration, and operational risks are reviewed.
- Release notes or PR summary are ready.
- Monitoring or post-release validation is defined.
- Communication owner and audience are identified when relevant.

# Codex Task Checklist

Use this checklist before handing a task to Codex.

## Implementation Readiness

- Goal is specific and actionable.
- Product source or PRD reference is named.
- Affected domain is identified.
- Likely files or directories are listed when known.
- In-scope and out-of-scope items are clear.
- Acceptance criteria are testable.
- Verification commands are listed.
- Data, API, security, configuration, and operations impact are considered.
- Rollback notes are included for risky changes.
- Open product questions are not hidden inside the implementation task.
